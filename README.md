# Password Generator

A simple password generator built with HTML, CSS, and JavaScript.

## Features

- Generate two random passwords
- Generates 15-character passwords
- Includes uppercase and lowercase letters
- Includes numbers and special characters
- Click a password to copy it to the clipboard

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Click **Generate Passwords**.
2. Two random passwords will be generated.
3. Click either password to copy it.
